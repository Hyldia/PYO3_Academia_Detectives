# Academia de Detectives

## Descripción del Proyecto

Academia de Detectives es un sistema de investigación lógica desarrollado en **Prolog** con una interfaz gráfica construida en **Python y Tkinter**.

El sistema permite a un investigador analizar casos por medio de una base de conocimiento compuesta por personas, lugares, objetos, eventos y evidencias. A través de consultas lógicas e inferencias, es posible identificar sospechosos, verificar coartadas, analizar contradicciones y obtener explicaciones sobre los resultados generados por el sistema.
